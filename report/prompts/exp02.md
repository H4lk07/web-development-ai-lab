# Experiment 2: Responsive Startup / Business Landing Page

## Aim
Develop a responsive landing page for a startup/business using Bootstrap and AI-assisted UI design tools.

## Technologies Used
HTML5, Bootstrap 5.3 (CSS + JS bundle), custom CSS3 overrides, responsive grid system, React 18 + Next.js App Router, TypeScript

## AI Tool Used
Antigravity

## AI-Assisted Implementation Prompt
```
Act as a product designer and Bootstrap 5 specialist. Create a responsive landing page for a fictional B2B analytics startup called "AuraMetrics AI".

STRUCTURE (in this order)
1. Sticky dark navbar — brand, links to Features / Telemetry / Pricing / Reviews, primary "Start Free Trial" button, collapses to hamburger below lg.
2. Hero — dark navy to blue gradient, headline, sub-headline, two CTAs and a mock dashboard visual made from simple divs (no external images).
3. Stats strip — four headline numbers (4.2B events, 2,100+ teams, 312ms latency, 99.99% uptime).
4. Features — six cards in a 3/2/1 responsive grid, each with an icon, title and description.
5. Pricing — three tiers (Starter, Pro, Enterprise), middle tier highlighted with a "Most Popular" badge.
6. Testimonials — interactive carousel with three client quotes.
7. Final CTA band and clean footer.

RULES
- Use Bootstrap classes and conventions for layout and components.
- Mobile-first; verify at 375 / 768 / 992 / 1440 px.
- Accessible: aria-labels on controls, sufficient contrast on gradient hero.
- Provide realistic telemetry copy, not lorem ipsum.
```

## Conclusion
A responsive startup landing page for AuraMetrics AI was built using Bootstrap layout grids and components with custom CSS accents. The collapsible navbar, testimonial rotation, and pricing cards behaved reliably at all screen breakpoints.
