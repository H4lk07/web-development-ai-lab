# Experiment 1: Responsive Personal Portfolio Website

## Aim
Write a program to create a responsive personal portfolio website using HTML5, CSS3, and Generative AI tools for code generation.

## Technologies Used
HTML5 semantic elements, CSS3 (custom properties, gradients, backdrop-filter, transforms), responsive layout via Tailwind CSS, React 18 + Next.js App Router, TypeScript, lucide-react icons

## AI Tool Used
Antigravity

## AI-Assisted Implementation Prompt
```
You are a senior front-end engineer and UI designer. Build a responsive personal portfolio as a single page for Mayank Goyal (JECRC University).

STYLE
- Theme: modern slate dark theme with indigo/purple accents and radial glow.
- Foreground: glassy white translucent panels, rounded 2xl corners, subtle borders.
- Navigation: clean header navigation with jump links and college lab badge.

CONTENT SECTIONS
1. Hero — availability pill, name (Mayank Goyal), role, short tagline, primary CTA.
2. Projects — responsive card grid, each card with title, description, tag badges and demo link.
3. About — academic background at JECRC University, competencies, milestone cards.
4. Skills — 4-column categorization: Frontend, Backend, Database, AI/DevOps.
5. Contact — two-column layout with contact details and a form (name, email, message) that shows a success message on submit.

ENGINEERING RULES
- Semantic HTML5 landmarks; one <h1> per page.
- Mobile-first responsive breakpoints at 640 / 768 / 1024 px.
- All interactive elements reachable by keyboard with visible focus.
- Form validation for required fields, valid email format, and minimum message length.
- Return production-ready, commented React code with no placeholder lorem ipsum.
```

## Conclusion
A responsive personal portfolio website was built with AI assistance on architecture planning. The navigation, semantic landmarks, project grid, and client-side contact validation functioned properly across mobile, tablet, and desktop viewports.
