[OBJECTIVE]: Construct a responsive personal portfolio single-page application for Mayank Goyal (JECRC University).
[STACK]: HTML5 Semantic Elements, CSS3 Custom Properties, Tailwind CSS, TypeScript, Next.js App Router.
[SECTIONS]:

- Strict semantic landmark hierarchy (<header>, <nav>, <main>, <section>, <footer>) with exactly one <h1>.

- Accessible ARIA labels and focus-visible keyboard navigation; return modular TypeScript code with zero lorem ipsum.
